# 两条条件性论文故事与完整实验体系

**两者是实质不同假设，不能同时当作已成立贡献。** 当前只拥有K1行为证据、K2复算与非盲质量筛查；下面所有新方法效果、机制、跨模型泛化均未实施。当前总体PIVOT，先走故事A的问题验证；失败后才考虑故事B。

## 故事A：动作—目标绑定的条件依赖

**候选题目**：*Grounding Risk in the Right Relation: Conditional Evidence Dependence for Multimodal Risk Detection*（暂定，不以名称暗示创新已成立）。

1. **一句话科学问题**：当物体与动作都被识别时，检测器是否依据正确的动作—目标关系作风险判断？
2. **Motivation**：现有K1只提示风险标签不一致；未来若KT2–4证明事实正确而绑定错误，并且干预绑定有选择性效果，才可写关系依赖不足的动机。
3. **现有研究不足的候选表述**：ThinkingGuard的步骤监督和近邻的安全方向未必确保判别器随正确关系变化；必须通过同预算baseline和干预证明，不能从文献未报告某指标推断其能力缺失。
4. **核心假设**：绑定特异的交互变量控制部分检测错误；全局提高Unsafe倾向无法同时修复这些错误和维持FPR。
5. **方法概览**：冻结VLM，关系条件交互头；对可信风险干预敏感、对审核为无关的变化稳定。技术定义见[候选1](H1_K2_Method_Candidates.md)。这些已知组件组合本身还不构成新技术贡献。
6. **模块贡献候选**：只有一个核心交互机制；不再加独立自评、门控和全局安全方向凑模块。若简单双线性/Prompt等效，方法贡献不成立。
7. **实验贡献候选**：事实、关系、后果、标签的分离诊断，以及干预选择性的证据；不把一张性能表拆成三条贡献。
8. **关键图表**：图1同事实不同目标的风险对照；图2正确/错误/无关绑定的控制实验；表1同FPR主结果；图3风险—误报曲线；表2同监督同计算消融；表3跨场景/跨数据/跨模型；图4运行成本。
9. **最强baseline**：ThinkingGuard合格五步协议、CrossGuard/ShieldVLM可获取实现、关系Prompt、DREAM式分解、Joint linear/concat MLP/低秩双线性、普通pair ranking、ShiftDC、HiddenDetect式特征。MMAligner-inspired只在同分类任务下说明改编。
10. **必要消融**：去掉关系选择、打乱target、只CE、相同pair数据通用ranking、无关干预、相同参数/标签/调用预算；与任意额外事实提示分离。
11. **审稿质疑回应条件**：“这只是更多监督”→所有方法共享原标签、关系信息和token预算；“只会看危险物体”→同物体动作目标改变与无关场景替换；“图像捷径”→独立真实图像/文本侧控制；“解释不忠实”→以干预行为为主证据而非CoT。
12. **缺证据**：可信残留错误数量、统一Prompt稳定性、事实/绑定真值、可独立grounding、现有强方法不能解决、新技术性质、独立外部验证。
13. **失败后PIVOT**：事实识别失败→换感知切口；Prompt修复→停止结构方法；标签不确定主导→故事B；全局阈值等效→不发明新模块。
14. **投稿定位**：若主要贡献是语义关系与判别机制，优先ACL/NeurIPS/ICLR/ICML；CCS需有明确检测威胁与适应性规避证据。会议目标不构成录用判断。

## 故事B：缺失语境中的可判定风险与拒判

**候选题目**：*When the Evidence Cannot Decide: Selective Multimodal Risk Detection under Missing Context*。

1. **一句话科学问题**：在授权、立场或指称条件缺失时，如何区分可判定风险与无法由可见证据决定的标签？
2. **Motivation**：K2看到若干缺证案例，但非盲筛查不够。未来两位人类在多个公开来源稳定确认这类歧义，且常规置信度无法区分时，动机才成立。
3. **候选文献缺口**：VLSU的Borderline是风险严重度，不是缺证；拒答对齐优化输出策略，不是判断的可识别性。然而选择性分类/不确定性moderation已成熟，需新增专门竞品检索，不宣称首次。
4. **核心假设**：一部分安全误判来自多个可行语境对应不同标签；这种结构性缺证与模型噪声/低置信度可区分。
5. **方法概览**：可见事实约束的有限条件集合，风险上下界与校准拒判；允许Safe/Unsafe/Review，技术草图见[候选2](H1_K2_Method_Candidates.md)。上下界对集合欠覆盖无保证，必须单独估计。
6. **模块贡献候选**：条件集合的可检验覆盖与选择性风险目标；不是给二分类器加第三标签。
7. **实验贡献候选**：同coverage下比较FNR/FPR，人工缺证一致性与条件补全改变标签的受控验证。
8. **关键图表**：图1同图文在显式有/无授权下的标签变化；图2可判定性与置信度交叉；图3风险—覆盖曲线；表1相同Review预算下错误率；表2条件集合欠覆盖；表3跨政策/来源/模型。
9. **最强baseline**：最优Dev阈值、置信度/熵拒判、两个Prompt分歧、conformal选择（说明交换性）、规则缺证器、给全部方法相同条件信息。
10. **必要消融**：不加条件集合、随机/不完整条件、条件数量、等调用数、错规范、只置信度、覆盖率匹配。
11. **审稿质疑回应条件**：“只是数据清洗”→新任务评价可判定性与稳定不确定，不用改GT提高旧分数；“拒判当然更准”→固定coverage/人工复核预算；“LLM幻想语境”→有限规则来源、人类冻结条件与欠覆盖审计；“规范不客观”→明确政策并报告分歧，不假装唯一真值。
12. **缺证据**：独立可判定性标注、外部复现、通用selective baseline失败、有限条件集合的可靠来源及新的算法必要性。
13. **失败后PIVOT**：条件不可稳定标注或简单置信度等效→NO-GO；只留下审计协议作为项目资源，不包装方法论文。
14. **投稿定位**：可判定性与语用/规范建模适合ACL/ML；安全会议需部署复核成本与规避风险实证，不能用泛伦理动机替代系统评价。

## 完整方法论文真正必需的实验

| 实验 | 目的与合格条件 | 级别/触发 |
|---|---|---|
| ID与严格分组split | Train/Dev/Test按pair、场景与近重复组划；36对仅探索 | 必需 |
| Cross-dataset | 与Train独立来源、标签目标可映射、图片实际可取；按缺图率报告 | 必需 |
| Cross-model | 一同源对照+至少另架构的小型公开模型；区分重新拟合与零迁移 | 对一般性主张必需，可分批 |
| PairAcc与干预质量 | 原全部结果与前瞻冻结可信组并列；风险/无关变化分开 | 故事A必需 |
| Recall–FPR曲线 | 同FPR阈值取Dev；报告测试偏移与CI，不能Test挑最好点 | 必需 |
| Risk–coverage | 固定复核预算、Review计成本，标签不确定与模型错误分开 | 故事B必需 |
| 强方法/Prompt基线 | ThinkingGuard、可得guard、Prompt-only、简单规则/分类头；同额外信息 | 必需 |
| 同监督/同计算 | 相同标签条数、关系信息、tokens、更新步、额外调用和调参预算 | 必需 |
| 关键模块消融 | 与机制预测直接对应，打乱关系/无关干预/全局偏置对照 | 必需 |
| 视觉遮挡/替换与文本扰动 | 遮挡只定位诊断，可能制造分布外；不自动当因果金标 | 机制主张必需 |
| 隐藏状态/证据干预 | 等norm随机、反向、正交、非目标层、prefill/decode区分 | 声称内部机制才必需 |
| 统计 | pair/scene-cluster CI、配对差值、多种子小头；主指标预注册 | 必需 |
| 量化与规模 | NF4与可运行更高精度/较小模型敏感性；先实测20GiB | 对量化机制主张必需，其余增强 |
| 延迟与显存 | 含预处理/加载和稳态分开，p50/p90、真实进程峰/状态缓存 | 必需 |
| 正常输入 | detector正常通过率/FPR/coverage；不直接称“过度拒答” | 必需 |
| 回复安全/帮助性 | 只有修改生成器或宣称下游安全时，额外测拒答/无害/帮助 | 条件必需 |
| 类别与失败分析 | 每类n及CI；稀有组不稳定排序；保留INVALID与失败 | 必需 |
| 数据许可/复现 | 固定revision、来源、限制、哈希、环境与完整输出 | 必需 |
| 大规模多模型榜单 | 不替代机制识别；当前不开展 | 暂停 |
| 70B、付费Judge、全量MCTS/GRPO | 不符合资源且非识别当前问题所必需 | 不执行 |

## 数据选择与资源拆分

- **TriggerBench**：官方Train可用于候选轻头；本轮36 Test已看过，不用于阈值/层训练。其余Test必须在设计冻结后一次性抽取、先做来源与近重复审核；这属于论文阶段，**不是当前扩测授权**。
- **MSSBench**：可优先调查外部情境配对与实际标签可映射性；它原来评价安全回应，不能直接把安全回复标签改称请求分类金标。原文报告1960对，ThinkingGuard相关工作写1820，必须按具体发布版本实查而不混用数字。
- **VLSU**：外部分类评测价值高，但官方test-only；不在其test上微调。Borderline和not_sure处理预注册，图片来自外网需下载可达性及许可审计。项目卡记录公开版本与论文数量差异，本轮未重算该全CSV。
- **MMIT / CrossGuard数据**：与隐含检测最接近，先核对许可、真值与Train来源，再决定使用；不能靠摘要假定可直接下载完整全部图像。
- **VLSBench / SIUO**：适合任务补充，风险请求、unsafe回答及正负例标签不同；不将其全部行简单贴Unsafe训练二分类。

特征提取按100个Train pair/任务的约200图分片；历史参考约2.35GPUh纯生成，预计总时间不精确，先测前向/状态缓存。小头训练CPU可多种子，代价主要是冻结VLM前向。多模型顺序装载，每任务≤6h、每进程≤20GiB；不要求独占整张卡超过任务窗口。完整论文可能需要多个独立小任务累积，不能把每次≤6h误称整篇论文6h完成。

## 论文主张的升级账本

现在可写：可复算的探索性现象及其测量边界。KT1/2通过可写：可信、统一定义下的残留失败。KT3/4通过可写：条件性行为机制线索。KT6通过可写：限定模型/变量/干预中的内部因果作用。方法击败同预算强基线并跨数据通过后才写：新方法有效。任何一步失败都应缩减或停止对应故事，不补造贡献。
