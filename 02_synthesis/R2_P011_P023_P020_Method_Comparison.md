## 2. P020 概率机制与消融（方法原文 §3/§5，阅读卡细节）

固定上下文 c、候选意义 m∈M、话语 u∈U、策略 r∈R、理性参数 α：

- L0：P_L0(m|c,u,r) ∝ f_r(c,m,u)P(m|c)，**在 M 上归一化**；f_r∈[0,1] 是策略条件下话语—意义的相容度，不是普通仇恨分类标签。
- S1：P_S1(u|m,c,r) ∝ P_L0(m|c,u,r)^α P(u|c)，**在 U 上归一化**，需要可比较的候选话语。没有足够区分性的候选，递归很难增加信息。
- L1：P_L1(m|c,u,r) ∝ P_S1(u|m,c,r)P(m|c)，**在 M 上归一化**。
- 未知 r：P_L1(m|c,u) = Σ_r P_L1(m|c,u,r) P(r|c,u)，可采用 soft 或硬策略近似。

数值表达受控实验使用规则 f_r；天气反讽实验拟合小网络并使用人类策略信息；LLM 实验通过语言模型条件概率间接刻画 f_r，**三种实现不能写成同一个端到端训练算法**。对 PragMega+ 有限选项集，整体正确意义平均概率：LLM RSA L0 0.73/L1 0.76；(RSA)² soft L1 0.80；hard L0 **0.85**/hard L1 0.84。这不是分类 F1。移除意义先验时 hard L1 约从 0.84 降至 0.51；移除话语先验基本无下降。原文表明现有改进不能主要归因于多层 RSA 递归，尤其文字表达替换可能过于近似。在字面子集，传统 LLM RSA L0 约 0.95，而最佳 (RSA)² L0 约 0.77，提示策略误判/过度非字面化。自动策略发现已在附录探索，不能当作未有人研究。

## 3. P023 核心审计（原文 §3–5）

- 七类：Ambiguous Homophone / Non-Lexical Homophone / Phonetic Substitution / Emoji / Orthographic / Cross-Lingual Phonetic / Cipher。前两类区别在编码后词形是否构成正常合法词组，而非上下文是否必需。
- 7,744 评论含 900 正例；184 种编码片段，111 种只出现一次。二分类最高报告 F1 0.78（DeepSeek-V3.2，特定提示）；策略类结果受样本量限制，Cross-Lingual N=7。
- 星级推断 MSE 并非解码准确率；解码后的输入不保证在所有模型上更好；编码与非编码评论非严格配对，不能据此声称编码导致全部性能落差。
- 种子→词典扩展→字符串匹配与翻译/拼音候选检索→人工核验，可能系统漏掉词典外/新义；筛选样本的正例率不是平台自然发生率。代码实现与覆盖偏差程度**待核验**。
- 原词恢复≠完整评价理解≠真实意图判别；P023 不直接评价隐式仇恨。

## 4. P011 提供的评测纪律

P011 是语用评测综述：现象分类、QA/NLI/多选等任务形式、Bottom-up 与 Top-down 数据来源、细粒度评测缺陷必须区别。高准确率并不等于通过隐含意义推理。其综述报告的纳入研究数在不同章节出现 57/58 不一致，保持原始差异而非擅自统一。

## 5. 结论与待核验

- **可支持**：三篇处于不同任务层次；有显式策略收益不等于有独立递归收益；分类或星级结果不能自动证明真实语用理解。
- **不可声称**：P023 完成开放式自动解码；P020 已解决未知代码词/开放修辞；P011 证明统一模型优越。
- **待核验**：P020 ACL vs arXiv v1 正式逐项版本差异；P023 的词典/检索实现及未见编码分割；完整本地复现开销。

**移交 R3：** 只允许构建可分支的概念流程；不能预设显式中间解释是完成所有任务的必要条件。
