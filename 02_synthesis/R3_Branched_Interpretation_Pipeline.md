# R3｜隐晦表达理解的可分支 Pipeline 与边界（定稿）

- 状态：2026-10-27 定稿；**概念框架，不是新算法/新评测结果**。
- 论文背景：[P011](https://aclanthology.org/2025.acl-long.425/)、[P023](https://aclanthology.org/2026.acl-long.426/)、[P020](https://aclanthology.org/2025.acl-long.1019/)。

## 1. 总体框架（允许反馈与跳步）

输入表达 x、可获得语境 c → 提出若干可能的机制/解释 → 按需要调用词典、语音、视觉、社群与篇章知识 k → 获取候选意义或直接预测 → 针对具体任务给出输出与不确定性。**识别机制、取证与解释可以互相迭代，不是固定顺序。**

## 2. 按语言机制分支

| 分支 | 可能的处理顺序 | 不可强制的步骤 |
|---|---|---|
| 谐音/字形/跨语言编码 | 发现异常形式→编码关系/候选生成→结合语境消歧 | 不必默认含修辞或有害性 |
| 隐喻/惯用语 | 语义映射或直接获取约定意义→情境解释 | 无须恢复“原始编码词” |
| 反讽/夸张 | 情境、说话者评价及期望→修辞解释 | 不一定存在正负极性取反 |
| Implicature/Presupposition | 交际关联性、触发结构、上下文→隐含命题/前提 | 不要求形式扰动 |
| 间接言语行为 | 场景/关系→主要请求、建议、断言等行为 | 不必假设“另一个词面意思” |
| Slang/Dialect | 使用现有词义惯例与语境 | 非规范形式不等于故意编码 |
| Meme/多模态 | 图文、传播模板与背景文化→解释 | 不必依赖文本解码 |
| Dogwhistle/动态代码 | 词语历史、社群与受众、时点→可能解释/效果 | 普通语义与特殊意义不一定构成可逆字典 |

## 3. 中间变量与证据

- 相对可观测：原始表达、提供的上下文、词形、部分编码片段、公开使用记录、人工标注。
- 部分可验证：编码对应关系、修辞分类、目标对象、上下文解释（受歧义及标注者背景影响）。
- 通常不可直接观测：真实心理动机、全部社群共有知识、每个受众的真实理解、唯一的开放式预期意义。
- 人工解码或解释可作为**数据集监督信号**，不能无条件当作真实心理意图。
- 存在多义时可保留候选集合 P(m|x,c,k)；缺乏必要证据时允许未确定/拒断。该概率表达仅为概念，非经验证的校准器。

## 4. 是否必须显式恢复中间意义？

**否。** 例如“灰常好吃”的编码识别、情感分类可能由直接模型给出，而无需输出“灰常→非常”；隐式有害性模型也可能直接预测。但结果正确不能证明内部确实完成该恢复步骤。反过来，显式解释不一定能改善最终分类。P023 解码后的星级预测并非所有条件更好；P020 RSA L1 不恒优于 L0。

## 5. 可支持结论与边界

- 支持：各种语言现象所依赖的可观察信息、候选意义形式和评测对象不同，因此**不能从三篇现有研究推出一个已验证的统一流水线**。
- 研究者推论：提供分支流程有助于明确评测单元和失败环节；**不能据此证明不存在未来可能的统一计算模型**。
- 待核验：多中间环节训练是否优于直接预测；多解释标签如何制定；真实上下文/受众知识的可得性；跨语言/多模态的完整评测协议。
