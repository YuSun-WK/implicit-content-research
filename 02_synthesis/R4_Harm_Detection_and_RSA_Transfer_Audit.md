# R4｜隐晦有害内容检测与 RSA 迁移条件审计（定稿）

- 状态：2026-10-27 定稿。本轮只做**任务边界与迁移可行性分析**；不提出论文 Idea、不确认新的 Research Gap。
- 主要原文：[P020](https://aclanthology.org/2025.acl-long.1019/)｜[P023](https://aclanthology.org/2026.acl-long.426/)｜[P011](https://aclanthology.org/2025.acl-long.425/)；补充比较建议：[ImpCon COLING 2022](https://aclanthology.org/2022.coling-1.579/) 等。

## 1. 区分八种研究任务

| 任务 | 典型预测目标 | 不应等同于 |
|---|---|---|
| 隐晦表达识别 | 有无语言现象及类型 | 仇恨 |
| 非字面意义理解 | 具体解释或候选意义 | 攻击意图 |
| 编码语言恢复 | 表面形式对应的常规内容 | 完整交际理解 |
| 隐式仇恨检测 | 带隐含贬损/仇恨的表达及其对象 | 一切隐喻/编码 |
| 隐晦辱骂检测 | 个人/对象攻击内容 | 必须有群体仇恨 |
| Dogwhistle Detection | 对特殊受众的代码语义或差异化效果 | 必定有害 |
| 动态黑话发现 | 新代码词及新义 | 静态词典匹配 |
| 上下文有害性判断 | 给定语境与标签规范下的危害类别 | 只解码原词 |

例如，“Newspaper Eat→不好吃”恢复的是消费负面评价，不能自动得出仇恨；“他们又来了”缺乏上下文和受众信息不能直接定性。危害类别依赖攻击目标、引用/否定/立场、语境与具体标签政策。语言理解与有害性判断相关，但既非充分条件，也不一定需要显式的中间解码步骤。

## 2. P020 RSA 的迁移假设：逐项裁决

| 条件 | P023 编码语言中是否满足 | 审计 |
|---|---|---|
| 可定义意义集合 M | 已知片段有部分人工解码 | **条件成立**；未知码词有 OOV 意义 |
| 预设策略集合 R | 有七类编码 taxonomy | **只部分成立**；编码策略不是修辞策略 |
| 候选话语集合 U | 有时可通过形式变体生成 | **待验证**；无区分性候选削弱 S1 |
| 相容函数 f_r(c,m,u) | 词典只能给出部分映射 | **不能直接等价**于概率相容度 |
| 可靠意义先验 P(m|c) | LLM/语言数据可估计 | **待校准**；跨社群与时间可能失效 |
| 策略后验 P(r|c,u) | 可考虑类别预测 | P023 F1 非概率校准证据 |
| 理性说话者的交际目标 | 部分编码促进圈内交流；可能规避圈外系统 | **不宜默认统一合作式听者** |
| 语境/知识共享 | 常见谐音可共享，社群新义未必 | **依赖受众/时点** |

**词典与 f_r 的层次差异：** 字典 D(u)=z 可以枚举候选解码；f_r(c,m,u) 表示在策略 r、语境 c 下 u 与目标意义 m 的条件相容度，可能需要构造候选与归一化、校准。有限集合 RSA 若遗漏真实意义 m*∉M，则无法给该意义分配概率。

**P020 的模型警告：** 其 L0/S1/L1 以可比较候选 U/M 为前提；现有实验证据未显示 L1 递归始终比策略条件 L0 更好，意义先验影响显著，字面情境存在退化。P020 还已尝试自动策略诱导，不得把简单聚类策略“发现”宣称为新方法。

## 3. 哪些迁移条件更可信？

- 较有希望满足部分前提：已知音近/字形编码、候选意义覆盖较好、编码规则可操作、上下文相对完整的狭窄任务。
- 障碍较大：未知新代码词、受众群体差异、历时语义漂移、缺乏可比较候选话语、特意对外隐藏的通信、超出有限 M 的开放式解释。
- 所有迁移评估都需要与词典/直接分类/直接 LLM 条件概率或已存在的词义消歧模型公平比较，不得只与弱基线比。

## 4. 工程约束

共享 RTX 4090/4090D，单卡计划峰值 16–20GiB，≤6h Kill Test，无付费 API。缓存概率或 CPU 重算 RSA 数学步骤可能较易；本地 7B/8B 量化 LLM 与大量替代表达的总体推理成本尚未实测；完整论文实验和未知码词的开放式搜寻不能被列为“已复现”。[P020 官方代码](https://github.com/cesare-spinoso/rsa_square)；[P023 官方数据/代码](https://github.com/Crowd-AI-Lab/CodedLang)。

## 5. 裁决与移交

- **论文直接支持：** P023 区分编码检测/策略分类/下游星级；P020 使用候选意义与策略条件推断，递归增益有限。
- **研究推论：** 编码形式恢复与概率语用推断可以相互衔接，然而迁移有效性未验证。
- **不能声称：** 编码=仇恨；解码=读懂心理意图；RSA 已经适用于动态黑话；未知编码/社群任务上的潜在限制即是新 Gap。
- **待核验：** 竞争工作、目标任务标签有效性、候选覆盖、可解释性、实际单卡复现成本。

**移交 R5：** 反向检查过强表述，确定下批阅读，而不是直接形成论文 Idea。
