The fixed public code tree contains README, an inference example, and images, but no search, reward, preference construction, or training implementation. The ACM supplement returned HTTP 403 during source audit (`docs/source_audit.md`); it remains **NOT_VERIFIED**. Status below distinguishes the public inference code from paper descriptions; `PAPER_ONLY` does not mean executable reproduction.
