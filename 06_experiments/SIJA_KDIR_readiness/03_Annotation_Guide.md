# 两阶段审核与实际交付

私有工作区实际包：`sija-rn2-private/review_pack/index.html`。另提供同目录的`KDIR_RN2_review_pack.zip`，下载解压后双击index.html即可离线使用，无需服务器、Token或网络。原图、指令、metadata与审核文件不入GitHub。

第一阶段只含4份实际资料：6张已存在图像（4源+2目标）、原始指令、CP-v1政策、可填写表、导出JSON和CSV空表。两份缺目标会明确提示。**这些是资料适配审核，不是已经合格的四格试验组。** 不含任何历史或新模型预测/解释；不需查看FA2来审核。没有可信Iu时请排除整组，不要把普通编辑凭空命名为去风险。

填写步骤：

1. 输入匿名审核者编号，例如R01。逐份核实源—指令—目标关联，说明哪里缺失。
2. 从视觉与固定政策确定是否有可定位风险，填写风险事实、r/a/s与er/en指令证据。找不到现成证据则留空并说明；禁止虚构逆编辑。
3. 写四格理想后果和ALLOW/BLOCK/UNKNOWN。确认er在Is仍有明确执行/幂等语义，去掉目标后无其它违规。未知授权/背景或法律争议写UNKNOWN，不硬判。
4. 填歧义、排除原因、政策条款和审核状态，点击“导出审核JSON”。导出含匿名编号、UTC时间、政策hash。浏览器保存草稿仅便利功能，导出文件才是交付记录。也可填写review_blank.csv。
5. 第二审核者应打开未填副本独立填写，不先看首评/预测。至少两名不同匿名审核者确认关键机制案例；分歧记录并解决后才可能变HUMAN_VERIFIED。当前所有资料PENDING。

SOURCE_LABEL仅指来源提供的编辑指令/分类；CODEX_DRAFT是本轮可用性判断；Codex看图、模型一致或表格字段完整都不等于HUMAN_VERIFIED。HTML的REVIEWED表示有人完成本次资料审核，不会自动准入实验。review_schema.json与group_template.json供之后记录完整组；validate_freeze.py强制32组合格及分组隔离。

第二阶段尚无K-DIR预测，包中不附历史输出。输入审核/双人分歧处理后冻结manifest，再运行未来推理。build_stage2.py只接受已FROZEN配置及匹配group_id预测，单独输出第二阶段HTML；第一阶段文件不回写。先看模型答案的审核者不能作为盲审首评，需要记录此偏离。

当前最有用的审核输出是：哪些资料应排除、缺哪一端或指令/风险事实。若确认都没有目标风险，保持数据门未过，不为满足数量新增生成或大规模标注。
