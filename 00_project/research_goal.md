# 研究目标与边界

长期目标：围绕广义隐晦信息检测，建立可核验的任务分类、技术发展地图和横向比较证据；在此基础上审查研究问题、跨领域方法迁移与实验可行性，最终形成高水平方法论文。

当前阶段只建设文献知识库。优先保留原文证据、版本差异、负面结果和不确定性；不以论文数量或想法数量代替证据质量。CCF-A / 顶级会议是目标，不是对当前研究结果的评价。

## 范围

- 核心：隐式仇恨、有害表达及其他依赖语境、语用、跨模态或文化背景的隐晦信息检测。
- 邻近：修辞、隐喻、讽刺、委婉语、代码词等形式与机制；需标明与目标检测任务的关系。
- 研究结论必须区分作者声称、实验支持、研究者推断与尚未验证的假设。

## 存储原则

GitHub 保存索引、阅读卡片、证据与实验记录。Zotero 保存文献和 PDF。大型数据集、模型权重、PDF、Zotero 数据库、账号信息与密钥不入库。
