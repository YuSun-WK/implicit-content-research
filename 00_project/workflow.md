# 研究工作流程

1. **文献阅读**：核对 DOI、版本和 PDF；提取任务、机制、数据、评测、结果及局限，并以章节、公式、表号或页码记录证据。卡片通过原文核验后才标为“已分析”。
2. **横向比较**：在相同任务、数据、标签定义和评测协议下比较方法；无法直接比较时明确差异。产出任务分类、方法分类、数据集表和比较矩阵。
3. **Gap 挖掘**：每个候选 Gap 获得独立编号，记录支持论文、原文证据、反面证据、适用边界及审查状态。证据不足时保留“待核验”，不得写成既成事实。
4. **跨领域迁移**：记录源领域方法的原始任务、计算机制、关键假设、迁移障碍与已有竞争研究；先验证目标任务条件是否成立。
5. **创新点审查**：关联 Gap 与源方法，查重近期工作，审查创新性、理论合理性、资源需求和可复现性；未通过审查的想法可归档但不包装成贡献。
6. **Kill Test**：设计最便宜且最能推翻关键假设的小实验，预先定义失败阈值、对照和停止规则。
7. **完整实验**：通过 Kill Test 后固定数据版本、代码版本、随机种子和配置，运行基线、消融、鲁棒性与误差分析；保存计划、配置、结果和结论，大型工件另存。
8. **论文写作**：用可追溯证据撰写问题、方法、贡献、实验与局限；每项核心主张应能回到论文原文或本项目实验记录。

阶段门槛：阅读卡片核验后才进入横向比较；Gap 的支持与反面证据审查后才进入迁移和 Idea；Kill Test 通过后才投入完整实验。
